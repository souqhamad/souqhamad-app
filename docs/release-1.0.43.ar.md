# الإصدار 1.0.43

تحسين تحميل صور الإعلان في التفاصيل والعارض: تحتفظ إعادة المحاولة بالمعاينة
الناجحة، ويظهر انتهاء الانتظار بعد 15 ثانية بدل استمرار مؤشر التحميل. تتشارك
التفاصيل والعارض معاينة مفكوكة على Android وiPhone ضمن ذاكرة محدودة، وتُحمّل
صور التفاصيل القريبة من الشاشة فقط. تظل الصورة الأصلية للنشط مع إيماءات التكبير
والسحب، وتبقى روابط CDN الحالية ثابتة.

تحديث كاش بيانات الصور بعد الحفظ والحذف وتعيين الرئيسية، وحماية النتيجة من
استجابات GET القديمة. يبقى رفع الصور الجزئي الناجح ظاهرًا إذا فشلت صورة لاحقة،
وتبقى العناصر الفاشلة قابلة للإعادة.

تغييرات السيرفر المقابلة في مستودع `smartstoreai1`: قراءة تفاصيل الإعلان مباشرة
مع `no-store`، واشتراط اكتمال نسخ الصورة الثلاث قبل حفظها، وإعادة محاولة أخطاء
التخزين المؤقتة، وتحسين التحقق من تفريغ كاش Cloudflare وتسجيل فشله. لم تتغير
مسارات API أو إعدادات حساب Cloudflare.

التحقق: نجاح 181 اختبارًا للتطبيق، و130 اختبارًا معزولًا للسيرفر، وفحوص
TypeScript وESLint. نجحت خمس حالات تفاعلية للعارض وثماني حالات للتصفح العام،
وظهرت الصور الثماني الفعلية باستخدام ملفات محلية معزولة. نجح تصدير Android
وiOS والويب؛ لا يمثل ذلك حزمة AAB/IPA موقّعة أو اختبار هاتف فعلي.

رمز البناء يستمر بالتزايد حسب `87 + PROJECT_BUILD_NUMBER` في Codemagic. يجب
اعتماد الرمز المطبوع في سجل البناء الجديد؛ لم يُفترض رمز ثابت للحزمة الموقّعة.
