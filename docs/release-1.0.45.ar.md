# الإصدار 1.0.45

يعالج هذا الإصدار تثبيت آخر رسالة عند فتح المحادثة وتغير مساحة العرض، مع
الحفاظ على موضع المستخدم عند قراءة رسائل أقدم. فُصلت نية التمرير اليدوي عن
أحداث التخطيط والتمرير البرمجي، مع نطاق مستقل لكل حساب ومحادثة.

حُدثت ترقيعات Expo المتوافقة داخل SDK 58، وأصبح عميل الرفع المباشر يتحقق من
Content-Length الموقّع مقابل بايتات JPEG الفعلية. يبقى رفع multipart قائمًا
عندما لا يعلن السيرفر تفعيل البروتوكول الجديد؛ لا يفعّل هذا الإصدار Cloudflare
Worker أو الحاويات والطوابير من تلقاء نفسه.

آخر إصدار مؤكد في Google Play هو `1.0.44` برمز بناء `159`. أصبح أساس رقم
البناء `160`، وتستخدم نسخ Codemagic على Android وiOS الصيغة:

```text
160 + PROJECT_BUILD_NUMBER
```

الحد الأدنى في Codemagic هو 161، والرقم الفعلي يطبع في خطوة
`Verify store build number`. لا يُفترض رقم العداد، ولا يُستخدم رقم workflow
المنفصل. تستمر الزيادة مقارنة بقاعدة الإصدار السابق 123 داخل المشروع نفسه.

يشمل دفع السيرفر المصاحب حماية ملكية الصور وتنظيفها الدائم، وحماية اعتماد
الرسوم من التزامن، وإنشاء عمولة بيع الإدارة، ومنع استعادة المحذوف، وربط OAuth
بالمتصفح، ومنع استرجاع جلسة برمز مستهلك، والتحقق من وجهات Web Push، وتجهيز AASA.
هذه تغييرات في مستودع `smartstoreai1` المستقل، وتحتاج اكتمال نشر AWS ومهاجراته.

تحقق الإصلاحات قبل تجهيز الإصدار: 230 اختبار تطبيق ناجحًا، و931 اختبار سيرفر
ناجحًا مع 43 متخطى، و42 حالة PostgreSQL معزولة ناجحة، و219 فحص متصفح وعقود HTTP
ناجحًا مع واحد متخطى. نجح البناء وتصدير المنصات؛ فحوص RN Web لا تثبت سلوك هاتف
أو FCM/APNs/OAuth أو R2 حي. تنبيهات تبعيات CLI وإعدادات Apple وCloudflare الحية
ما زالت موضحة في تقرير إصلاحات الإنتاج بالسيرفر.
