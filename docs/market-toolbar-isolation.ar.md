# عزل تحديثات شريط السوق عن البطاقات

فُصلت تحديثات الشريط عن رسم قائمة الإعلانات مع الحفاظ على تنسيق الحركة
والتصنيفات والبحث والمنطقة والموقع والفلاتر وإنشاء الإعلان والتحميل المتتابع.
لم تتغير مسارات API أو طريقة جلب الإعلانات.

## حدود المكوّنات

- `use-market-toolbar.ts`: يحتفظ بحركة الشريط وإشارات التمرير والسحب اليدوي
  وإعادة ضبط نتائج الفلاتر. حالة إخفاء الأدوات قيمة مشتقة على مسار التحريك،
  ولا تعود إلى React state في شاشة السوق.
- `market-toolbar-tools.tsx`: يتولى وحده تحويل إخفاء الأدوات إلى حالة لمس
  وإمكانية وصول. تغيّر هذه الحالة يحدّث فرع الأدوات دون القائمة.
- `market-feed.tsx`: قائمة مستقلة مغلفة بـ`memo`، مع بطاقات وفواصل ثابتة
  ودوال مستقرة. تبقى رأس القائمة ونهايتها ومؤشر التحديث داخل حدود القائمة.
  تحديث بيانات إعلان أو تحميل صفحة جديدة أو تغيير السمة يظل يحدث العرض.
- `market-screen.tsx`: يحتفظ ببيانات البحث والفلاتر وإجراءات الصفحة، ويوصل
  للقائمة القياسات الفعلية وإشارات التمرير دون تمرير حالة إخفاء الأدوات إليها.

## أول بطاقة والمسافات

يساوي الحيز الأول ارتفاع الأدوات وصفوف التصنيفات المحتفظ بها وحدود الشريط
وحشوه: 10 نقاط للحدود والحشو، دون الفاصل الإضافي السابق البالغ 8 نقاط.
لذلك تلتقي أول بطاقة بحافة الشريط. لا يتغير هذا الحيز مع كل إطار من التحريك.

بقي تعويض موضع أول بطاقة أثناء السحب اليدوي قرب بداية القائمة كما كان؛
التمرير العادي والقصور الحركي لا يصدران أوامر تمرير تنافس حركة العميل.
تظل بطاقة عميقة في القائمة ثابتة بالنسبة لموضع التمرير عند سحب الشريط يدويًا،
وتبقى التصنيفات الأساسية أو آخر صفين من الفروع ظاهرين وفق الاختيار.

## التحقق المحلي

- 220 اختبارًا ناجحًا دون فشل أو تخطٍّ. منها اختبار المكوّنين الحقيقيين عبر
  React وReactDOM داخل Chromium: تبديل حالة الشريط لا يعيد رسم القائمة أو
  تركيب البطاقات، وإضافة دفعة جديدة تظل تحدثها.
- فحص TypeScript وESLint ناجح دون تحذيرات.
- نجحت 14 حالة مرئية على حزمة React Native Web: السحب اليدوي، القائمة
  القصيرة، الاتجاهان والقصور الحركي، تفرعات التصنيفات، تغيير ارتفاع الأدوات،
  ثبات البطاقات العميقة والأخيرة، الوضعان الفاتح والداكن، وتحميل الصفحات ومنع
  تكرار الإعلانات. لم تظهر أخطاء تشغيل في المتصفح.
- نجحت حالة إضافية بإدخال لمس لتفرعات التصنيفات وحركة القائمة. التحقق من
  الالتقاء بعد تغيير الفروع يسمح بفارق قياس لا يتجاوز 1.5 نقطة.
- الفجوة المقاسة في بداية الحالة المرئية الأساسية كانت صفرًا. اختبارات
  التعويض تراعي هامش التمرير الأصلي تحت ربع نقطة أثناء الاستقرار.
- نجح تصدير Web وAndroid وiOS. ملفات التصدير والفحوص تحت `.data` ومتجاهلة
  من Git.

أهم السجلات:

```text
.data/toolbar-isolation-tests.log
.data/toolbar-isolation-check.log
.data/toolbar-isolation-browser/report.json
.data/toolbar-isolation-touch/report.json
.data/toolbar-isolation-export-final.log
```

هذا يثبت عزل تحديثات React والسلوك المقاس محليًا. لم ينفذ قياس سلاسة الإطارات
على جهاز Android أو iPhone فعلي؛ لا تمثل محاكاة المتصفح شهادة بزوال كل رعشة
على الأجهزة. لم يرفع الإصدار ولم تدفع هذه التعديلات إلى المستودع ضمن هذه الخطوة.
