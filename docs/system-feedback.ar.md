# رسائل إجراءات العميل

تعرض إجراءات التطبيق الحالية نتيجتها برسائل قصيرة بهوية سوق حمد، في النمطين الفاتح والداكن. يستخدم النجاح لون النجاح المعتمد، والفشل لون الخطأ، والمعلومات ألوانها الموجودة في `theme.ts`. تظهر الرسالة تحت الترويسة مع زر إغلاق. تبقى الأخطاء حتى إغلاقها أو بدء محاولة جديدة؛ الرسائل المعتادة تختفي بعد فترة، وتبقى لقارئ الشاشة حتى إغلاقها. تأكيدات النشر والحذف والحظر تستخدم واجهة موحدة مع الحفاظ على نص القرار والأزرار والإلغاء.

| القسم | الإجراءات المرتبطة بالرسائل |
| --- | --- |
| حسابي | حفظ الاسم والرقم، تحديث الصورة وإزالتها، حذف الحساب، تسجيل الخروج، اختيار المظهر، المتابعة وإلغاؤها |
| الإعلانات | الحفظ والنشر، اختيار الصور ورفعها عند الحفظ، إزالة الصورة وتعيين الرئيسية، إيقاف الإعلان وحذفه وتسجيله كمباع |
| تفاصيل الإعلان | المفضلة، البلاغ، المشاركة، تعذر الاتصال؛ متابعة المشابه تبقى برسالتها الحالية داخل الصفحة |
| المعلن | المتابعة والتقييم والبلاغ |
| المحادثات | الإرسال، حذف الرسالة أو المحادثة، الحظر وإلغاؤه، مشاركة رقم التواصل |
| الرسوم | حفظ قيمة البيع ونسخ بيانات التحويل؛ لا تعني أي منهما تسجيل الدفع |
| الإشعارات | تحديد المقروء، الحذف، تفعيل إشعارات الجهاز وإيقافها؛ أخطاء صلاحية الجهاز تعرض ضمن إعدادها |
| حمد | اختيار المرفقات وإزالتها، بدء محادثة جديدة، ورسائل التحقق الحالية؛ حالة الرد والخطأ تبقى في المحادثة |

نتائج الحفظ والنشر والتغييرات الخادمية تنتظر استجابة السيرفر. اختيار الصور محليًا يحمل عبارة توضح أنها سترفع عند الحفظ. لا يتغير أي مسار API أو تصنيف أو حقل أو شرط نشر أو نسبة رسوم. لا توجد درجات اكتمال أو نسب مشاهدات أو نصائح جديدة، ولا تنشئ هذه الرسائل إشعارات Push أو سجلات إشعارات إضافية.

`feedback-store.ts` يحصر الرسائل في حسابها، يزيل التكرار، ويحد عدد الرسائل المنتظرة ويقدم الخطأ على النجاح. ينسق عرض نسخة واحدة فوق الشاشة أو النافذة المفتوحة. `useActionMutation` يحفظ سياق الاستدعاء الأصلي ويمنع إكمال واجهة حساب آخر بنتيجة متأخرة. يزول تأكيد الإجراء عند مغادرة مساره. لا تلتقط المنظومة طلبات الشبكة العامة ولا تعرض نجاحًا عند إعادة الجلب الخلفية.

## التحقق وحدوده

اختبارات الوحدة تتحقق من عزل الحساب، وسياق التغييرات، والإلغاء والتأكيد، وتكرار الرسائل والأولوية. `node tests/feedback-browser.cjs` يستخدم تصدير React Native Web وواجهات API معزولة لاختبار حفظ الحساب وفشله في النمطين، وحذف الحساب مع الإلغاء، والمفضلة والبلاغ، وفشل النشر وإعادة المحاولة داخل المعاينة دون اشتراط الصور. هذا فحص واجهة ويب للتطبيق؛ لا يثبت وصول إشعارات جهاز أو عمل OAuth أو قارئ الشاشة على Android/iPhone فعلي.

تحقق 26 أكتوبر 2026: نجح TypeScript وESLint و**103/103** اختبارًا آليًا، و**5/5** حالات واجهة للرسائل و**8/8** حالات الواجهة السابقة. نجح تصدير Android وiOS والويب، وفحص حزمة Android المنفصلة **27 أصلًا و39 موردًا** دون تعارض أسماء. لا توجد تغييرات في تبعيات native أو إعدادات التوقيع أو مستودع السيرفر؛ يحتاج المستخدم تثبيت بناء جديد ليرى الواجهة المحدثة.
