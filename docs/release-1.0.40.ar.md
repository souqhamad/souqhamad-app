# مراجعة استجابة أدوات السوق — 1.0.40

أثبتت المراجعة حالتين إضافيتين: اختيار تصنيف من الأدوات المطوية يعيد فتح الجزء العلوي، وتغيّر ارتفاع الأدوات بسبب رسالة السوق أثناء انتهاء السحب قد يوقف الحركة بين موضعين. كما أن استبدال نتائج طويلة بنتائج أقصر يجعل القائمة تضبط إزاحتها تلقائيًا، وكان الشريط يفسر ذلك كتمرير عكسي من العميل قبل تنفيذ إعادة الضبط.

يحافظ اختيار التصنيف الآن على موضع الأدوات، ويبدأ نتائج التصنيف تحت الصفوف المحتفظ بها. تتبع إزاحة البداية ارتفاع الأدوات الفعلي عند ظهور زر مسح الفلاتر أو تغيّر القياسات. يفتح البحث النشط الأدوات كما سبق. لا يُستخدم تغيّر أبعاد القائمة أو النافذة وحده لتحديد اتجاه تمرير العميل.

تحتفظ الحركة بنقطة الاستقرار المقصودة عند إعادة قياس ارتفاع الأدوات، وتستأنف الانتقال إلى الفتح أو الطي. إذا تغيّر القياس والإصبع ما زال يسحب، تُضبط نقطة انطلاق الإيماءة ويستمر تحكم العميل. يمكن مقاطعة انتقال قائم بسحب جديد. تبقى مقدمة القائمة ثابتة أثناء حركة الطي والفتح، وتبقى آخر فئتين من التصنيفات أو الفئة الرئيسية ظاهرة.

تتضمن المراجعة سحبًا فعليًا للبطاقات باللمس في معاينة React Native Web، وعكس الاتجاه، والحركات الصغيرة، والثبات بعد توقف الإدخال، واختيار تصنيف والشريط مطوي، وتغيّر الارتفاع أثناء انتهاء السحب. أُضيفت اختبارات تنفيذ للخطاف الحقيقي مع ترتيب اكتمال وإلغاء حركات Reanimated؛ فشل المصدر السابق في حالتي إعادة القياس وإعادة ضبط التصنيف، وفشل حارس ضبط الأبعاد عند تعطيله وحده.

لم تتغير مسارات API أو آلية تحميل الصفحات أو بيانات الإنتاج. التحقق المعزول وتصدير حزم Android وiOS لا يثبت معدل الإطارات أو إحساس السحب على جهاز فعلي؛ لم يكن جهاز متصلًا أثناء المراجعة.

نجح فحص TypeScript وESLint، و142 اختبارًا، و28 حالة حركة مستمرة (14 بالماوس و14 باللمس) دون أخطاء متصفح. نجح تصدير Android وiOS والويب. في حالة اختيار التصنيف بقي ارتفاع الأدوات الظاهرة صفرًا، وظهرت الفئتان المحتفظ بهما، وبقي الفاصل قبل أول بطاقة 8 نقاط. احتُفظ بنتائج خط الأساس الفاشلة محليًا للمقارنة.

رقم الإصدار `1.0.40`. يستمر رمز البناء المتزايد من إعداد Codemagic الحالي، ويظهر الرقم الفعلي في خطوة Verify store build number.
