# إصلاحات الملف الشخصي وتوافق Expo — 1.0.37

## السلوك المصحح

يحفظ السيرفر الاسم والصورة الموجودين في قاعدة البيانات عندما تهيئ عملية متابعة أو تقييم أو إنشاء إعلان حسابًا موجودًا. لا تستبدلهما قيم الجلسة القديمة، بما يشمل مسح الحقول إلى `null`. ما يزال إنشاء حساب جديد يستخدم الهوية الموثقة، مع الحفاظ على عقد البريد والصلاحيات. إصلاح السيرفر في مستودع SmartStoreAI داخل `agent/marketplace/repository.ts`.

تلتقط عملية صورة الحساب في التطبيق رمز الجلسة وجيلها قبل اختيار الصورة، وتتحقق منهما بعد مراحل التجهيز وقبل إرسال الطلب. يبقى الطلب ملزمًا بهذه الهوية أثناء انتظار قراءة الصورة على الويب أيضًا. يُرفض تبديل الحساب والعودة إلى الحساب الأصلي أثناء العملية؛ لا يكفي تطابق الرمز وحده. تُحرر موارد الصورة عند الإلغاء والفشل.

لا توجد مسارات API جديدة أو تغييرات في مخطط قاعدة البيانات أو وظائف العميل أو تصميم الواجهات. يتطلب وصول حماية الصورة تثبيت بناء التطبيق الجديد، ويتطلب وصول إصلاح حفظ البيانات نشر كود السيرفر.

## توافق الحزم

حُدّثت سبع حزم ضمن SDK 58 باستخدام `expo install --fix`: Expo إلى `58.0.19`، وdev-client إلى `58.0.15`، وfile-system إلى `58.0.11`، وfont إلى `58.0.10`، وimage إلى `58.0.17`، وlocation إلى `58.0.19`، وrouter إلى `58.0.26`. جرى تحديث القفل، وأصبح `expo install --check` ناجحًا.

يبقى تدقيق الاعتماديات يعرض تنبيهين High داخل Expo CLI. لم يُسكت التدقيق ولم يُفرض تبديل واجهة Zod الرئيسية أو تُضف رقعة تشفير غير مدمجة. [حالة التنبيهين وحدود الاستخدام](expo-toolchain-security.ar.md).

## التحقق

- نجح فحص TypeScript وESLint للتطبيق، و131 اختبارًا، منها 18 حالة تراجع لربط رفع الصور بالحساب ومرحلة تجهيز الصورة.
- نجح تصدير Android وiOS والويب من الحزم المحدّثة.
- نجح فحص موارد Android: 27 أصلًا و39 موردًا دون أسماء متكررة.
- نجحت اختبارات الواجهة المعزولة على React Native Web: 8 حالات تصفح و5 لرسائل الإجراءات وحالتان للمحادثات، دون أخطاء متصفح. لم تتغير واجهات الحساب أو المحادثة في هذا الإصلاح.
- نجح فحص TypeScript وESLint لتغيير السيرفر؛ نجحت مجموعة السيرفر المعزولة: 877 حالة، دون فشل، مع 20 تجاوزًا مشروطًا بتفعيل اختبارات قاعدة البيانات.
- نجحت اختبارات حفظ الملف الشخصي الثلاثة؛ أثبت تشغيل الكود القديم فشل حفظ القيم المعدلة والممسوحة. نجح اختبار PostgreSQL محلي حقيقي بعد الإصلاح، وفشل الكود القديم بعد المتابعة. يختبر المسار تعديل الحساب ثم متابعة وتقييم وإنشاء مسودة، وتكرار ذلك بعد مسح القيم.
- أُدرج اختبار PostgreSQL الجديد في مشغّل قاعدة الاختبار المحلية. يرفض الاتصال بقاعدة خارج `127.0.0.1:55432/smartstore_codex_test`.
- نجحت مجموعة قاعدة الاختبار المحلية بعد إدراجه: 19 اختبارًا، دون فشل أو تجاوز.

لم تُعدّل بيانات العملاء على الإنتاج ولم تُنفذ عملية مصادقة أو رفع صورة أو تغيير حساب على هاتف حقيقي أثناء هذه الإصلاحات. الاختبارات المعزولة لا تثبت وصول إشعار جهاز أو سلوك أذونات النظام. رقم الإصدار `1.0.37`، ويبقى رمز البناء متزايدًا عبر `87 + PROJECT_BUILD_NUMBER` في Codemagic.
