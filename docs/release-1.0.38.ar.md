# ثبات حركة السوق — 1.0.38

أظهر تسجيل الهاتف قفز البطاقات وتذبذب أدوات السوق أثناء السحب، مع ظهور مؤشر التحديث الأصلي أثناء التصفح. كان طي الأدوات يغير ارتفاع مقدمة القائمة في كل إطار، ويتداخل مع التمرير وتعويض موضع البطاقات. وكان مؤشر السحب للتحديث مرتبطًا بإعادة جلب البيانات في الخلفية.

أصبحت مقدمة القائمة ثابتة الارتفاع أثناء الحركة. تتبع الأدوات اتجاه التمرير على خيط الواجهة باستخدام Reanimated، ويعمل السحب اليدوي عبر Gesture Handler. يتحرك أول إعلان مع الأدوات عند بداية القائمة فقط، وتبقى البطاقات العميقة في موضعها أثناء السحب اليدوي. تبقى مساحة كافية لهذا السلوك حتى عندما تعيد الفلاتر إعلانًا واحدًا. تُزامن نهاية الحركة صراحةً قبل إنهاء السحب، بما يشمل وضع تقليل الحركة.

تستخدم أزرار السوق مكوّن الضغط المتوافق مع الإيماءات لمنع فتح إنشاء الإعلان أو اختيار تصنيف عند سحبه رأسيًا. يستمر التمرير الأفقي للتصنيفات واختيار آخر مستويين والتحميل المتتابع ومنع تكرار الإعلانات. لم تتغير مسارات API أو بيانات الإنتاج.

لم يعد التحديث في الخلفية يشغّل مؤشر السحب الأصلي. يبدأ المؤشر من سحب العميل فقط، ويمنع تداخل التحديثات وينتظر الإعلانات والإعدادات قبل الانتهاء. ثُبّتت مراجع بيانات البطاقات وعارضها بين تحديثات حالة الأدوات، وأُوقف فصل البطاقات الأصلية بسبب القص أثناء التمرير مع استمرار المحاكاة الافتراضية للقائمة.

توجد اختبارات مستمرة لكل إطار لثبات ارتفاع محتوى القائمة، والمسافة بين أول بطاقة والأدوات، وثبات بطاقات منتصف القائمة ونهايتها، وعدم استمرار الحركة بعد توقف الإدخال. تغطي الحالات أيضًا قائمة قصيرة، وتقليل الحركة، والأزرار والبحث والتمرير الأفقي، والتحميل ومنع التكرار، وحجب البطاقات عند حواف الأدوات في النمطين الفاتح والداكن. اختبارات مؤشر التحديث تغطي الخلفية والفشل وتكرار السحب ومغادرة الشاشة.

التحقق عبر React Native Web وواجهات API معزولة لا يثبت معدل الإطارات أو تداخل الإيماءات الأصلي على الهاتف. يحتاج التحقق النهائي من التسجيل نفسه إلى تثبيت بناء جديد على الجهاز؛ لم يكن جهاز متصلًا أثناء العمل. تصدير Android وiOS ينتج حزم JavaScript/Hermes، ولا يمثل AAB أو IPA موقّعًا. يبقى التوقيع والبناء الأصلي في Codemagic.

نجح فحص TypeScript وESLint، و137 اختبارًا، و20 حالة حركة مستمرة (10 بالماوس و10 باللمس)، و8 حالات تصفح معزولة دون أخطاء متصفح. نجح تصدير Android وiOS والويب، وفحص موارد Android من تصدير خاص بأندرويد: 27 أصلًا و39 موردًا دون تكرار، وفحص توافق الحزم عبر `expo install --check`. لم تُغيّر اختبارات الواجهة بيانات الإنتاج.

رقم الإصدار `1.0.38`، ورمز البناء في Codemagic هو `87 + PROJECT_BUILD_NUMBER` كما في الإصدار السابق.
