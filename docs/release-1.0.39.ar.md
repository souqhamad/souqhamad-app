# تبسيط المحادثة وأزرار إنشاء الإعلان — 1.0.39

أزيلت حاوية «وش تحب نبدأ فيه؟» واختصاراتها من بداية محادثة حمد، والنص الدائم عن حفظ المحادثة، والإرشاد الدائم أسفل محرر الرسائل. تبقى تحية حمد، والكتابة والإرسال والصور والمحادثة الجديدة. تظهر حالة تجهيز الصور أو فشل الحفظ عند الحاجة فقط. لم يتغير منطق حفظ المحادثة أو اتصالها بالسيرفر.

أصبح ارتفاع زري «إعلان مع حمد» و«إعلان يدوي» في أدوات السوق 32 بدلًا من 36، مع خط أصغر وأخف وأيقونات أصغر. بقي العنوان في سطر واحد، مع ضبط حجم النص لعرض الزر وحصر تضخيم خط هذا العنصر فقط حتى لا يلتف إلى سطرين. يستمر السحب اليدوي للأدوات ومسارا الإنشاء الحاليان.

نجح فحص TypeScript وESLint، وتصدير Android وiOS والويب. جرت معاينة الأزرار على عروض 320 و360 و412 في النمطين، بارتفاع 32 ونص في سطر واحد. نجحت حالتا تخطيط المحادثات، بما يشمل إرسال رسالة ورد حمد وإعادة تحجيم مساحة الكتابة، وحالتا سحب الأدوات باللمس (تمييز السحب عن الضغط وتتبع أول بطاقة). هذه معاينة React Native Web بواجهات API معزولة، ولا تمثل اختبار لوحة مفاتيح أصلية أو جهاز فعلي.

رقم الإصدار `1.0.39`. يستمر Codemagic في إصدار رمز بناء متزايد وفق `87 + PROJECT_BUILD_NUMBER`.
